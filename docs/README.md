# AERON static portfolio demo

`docs/index.html` is a standalone, **scenario-based** preview of the Knowledge
Graph/RAG project. It uses fictional, prewritten examples and makes no claims of
live Neo4j or LLM execution. It must not be used for aircraft maintenance.

Original full application: `npm start` with appropriate Neo4j configuration.
Original Physical AI PoC: see the repository root README.

Publish this static preview on GitHub Pages after merging:
Settings > Pages > Deploy from a branch > main > /docs.
GitHub Pages configuration and publication require repository-owner action.

Use separate URLs for the GitHub source and deployed demo; the latter only exists
once GitHub Pages is enabled and successfully deployed.
