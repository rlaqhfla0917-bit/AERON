# AERON 공개 웹 시연

`docs/index.html`은 Neo4j Knowledge Graph + RAG 기반 항공정비 정보 탐색 서비스를 소개하는 **정적 웹 미리보기**입니다.

- 화면의 질문과 응답은 미리 작성된 가상 시나리오입니다.
- 공개 웹 데모는 실제 Neo4j 데이터베이스, LLM API, 정비 교범에 연결되지 않습니다.
- 실제 정비 판단에 사용해서는 안 됩니다.
- 원본 Node.js 지식 탐색 서비스 구조와 실행 방법은 [상위 README](../README.md)에 설명되어 있습니다.

## GitHub Pages

저장소 Settings → Pages에서 `Deploy from a branch`, `main`, `/docs`를 선택하면 공개됩니다.
